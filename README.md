# Minecraft Mod/Shader Helper

Простое приложение для Windows, которое помогает добавлять моды (.jar) и шейдеры (.zip или папки) в папку Minecraft (%appdata%\.minecraft).

---

## Что делает
- Копирует .jar-файлы модов в `%appdata%\.minecraft\mods`.
- Копирует .zip-файлы шейдеров или упаковывает и добавляет папки шейдеров в `%appdata%\.minecraft\shaderpacks`.
- Перед изменением создаёт zip-резервные копии папок `mods` и `shaderpacks` в `%appdata%\.minecraft\mod_shader_backups`.
- Ведёт лог операций в `mod_shader_helper.log` (в папке .minecraft).
- Не запускает сторонние инсталляторы (например, OptiFine installer). Если вы используете OptiFine.jar, приложение просто скопирует его в `mods`.

---

## Быстрый путь: получить готовый EXE через GitHub Actions
1. Создайте репозиторий на GitHub (или используйте существующий).
2. Добавьте файл `minecraft_helper.py` в корень репозитория.
3. В веб-интерфейсе создайте файл `.github/workflows/build-windows.yml` со workflow (или добавьте его в репо).
4. Сделайте push в ветку `main` (или `master`) — workflow запустится автоматически. Или вручную запустите `Run workflow`.
5. После завершения откройте Actions → ваш запуск → справа найдите секцию Artifacts → скачайте артефакт `minecraft_helper` (внутри `dist/minecraft_helper.exe`).
6. Отправьте этот `minecraft_helper.exe` подруге — ей не нужен Python.

## Локальная сборка (опционально)
Если хотите собрать .exe сами на своём компьютере:
1. Установите Python 3.8+ (рекомендуется 3.10).
2. Установите зависимости:
   - pip install PySimpleGUI pyinstaller
3. В каталоге с `minecraft_helper.py` выполните:
   - python -m PyInstaller --onefile --windowed --name minecraft_helper minecraft_helper.py
4. Итоговый файл: `dist\minecraft_helper.exe`.

## Как пользоваться (для подруги)
1. Скопируйте `minecraft_helper.exe` на её компьютер и запустите (двойной клик).
2. Откроется окно:
   - Поле "Папка Minecraft" обычно заполняется автоматически (`%appdata%\.minecraft`). Если пусто — выберите папку вручную.
   - Нажмите "Добавить мод (.jar)" и выберите нужный `.jar` — программа создаст резервную копию папки `mods` и скопирует файл туда.
   - Нажмите "Добавить шейдер (файл / папка)" — можно выбрать `.zip` или папку шейдера. Программа создаст резервную копию `shaderpacks`, затем скопирует или упакует и добавит шейдер.
   - После успешной операции появится сообщение "Всё выполнено".
   - Через кнопку "Открыть логи" можно просмотреть `mod_shader_helper.log`.

## Важные замечания и безопасность
- Программа НЕ проверяет содержимое модов/шейдеров на безопасность. Рекомендуется сканировать скачанные файлы антивирусом.
- Windows SmartScreen может предупредить при запуске самодельного EXE — это нормально. Можно разрешить запуск.
- Программа не выполняет инсталляторы и не изменяет профили Minecraft (кроме копирования файлов в `mods`/`shaderpacks` и создания бэкапов).
- Рекомендуется создавать резервную копию всего `.minecraft` перед массовыми изменениями.

---

## Устранение неполадок
- Если приложение не находит папку Minecraft — убедитесь, что игра установлена и `%appdata%\.minecraft` существует; можно указать папку вручную.
- Если exe не скачался из Actions — проверьте логи workflow; возможные ошибки: отсутствует `minecraft_helper.py` в корне репозитория или PyInstaller вернул ошибку.
- При проблемах пришлите `mod_shader_helper.log` из папки .minecraft — в нём описаны операции и ошибки.
